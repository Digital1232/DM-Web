SCOPE ISSUES EXPLAINED
──────────────────────────────────────────────────────────────────────────────

Problem:
The main application code in index.html uses an IIFE (Immediately Invoked 
Function Expression) to encapsulate state variables like:
  - currentUser
  - allTimeLogs
  - tasks
  - currentReportTab
  - activeView
  - reportDateFrom
  - reportDateTo

These are defined with 'let' and 'const' inside the IIFE, making them local 
to that scope and NOT directly accessible from external modules like 
employee-dashboard.js and employee-client-timing-report.js.

Solution:
The main application exposes these variables to the window object so they can 
be accessed from external modules. The external modules need to reference them 
as window.variableName instead of just variableName.
