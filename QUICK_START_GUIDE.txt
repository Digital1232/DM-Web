🔍 ROOT CAUSES & SOLUTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

┌─ API TOKEN ISSUES
│  ├─ Check: https://id.atlassian.com/manage/api-tokens
│  ├─ Verify: Token is NOT expired (created within 1 year)
│  ├─ Verify: Has scopes: offline_access, read:jira-work, write:jira-work
│  └─ Fix: Create new token if needed
│
├─ WRONG PROJECT KEY
│  ├─ Check: https://vilpowerdigitalmarketing.atlassian.net/projects
│  ├─ Verify: Project 'J2' exists in the list
│  └─ Fix: Update projectKey in jiraConfig
│
├─ GOOGLE SCRIPT DOWN
│  ├─ Check: Open gsUrl directly in browser
│  ├─ Verify: Script loads without error
│  └─ Fix: Redeploy Google Script and update URL
│
├─ EMPTY PROJECT
│  ├─ Check: Open project J2 in Jira
│  ├─ Verify: Project has tasks/issues
│  └─ Fix: Create test tasks in project
│
├─ WRONG AUTH EMAIL
│  ├─ Check: Google OAuth or token owner
│  ├─ Verify: authEmail matches token owner
│  └─ Fix: Update authEmail in code
│
└─ MISSING PERMISSIONS
   ├─ Check: Token scope requirements
   ├─ Verify: User can access project
   └─ Fix: Create new token with correct scopes
