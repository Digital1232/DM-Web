BACKEND FUNCTIONS (What Gets Deployed)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. /api/meta/connect (POST)
   ↳ Initiate OAuth flow
   ↳ Returns: OAuth URL

2. /api/meta/callback (GET)
   ↳ Handle OAuth callback
   ↳ Exchange code for token
   ↳ Fetch business data
   ↳ Store in Firestore

3. /api/meta/profile (GET)
   ↳ Get user connection data
   ↳ Returns: All profile info

4. /api/meta/disconnect (POST)
   ↳ Remove connection
   ↳ Delete all data

5. /api/meta/sync (POST)
   ↳ Update latest data
   ↳ Refresh follower counts

6. /api/meta/refresh (POST)
   ↳ Check connection status
   ↳ Validate token

"Cannot find module firebase-admin"
  → npm install firebase-admin node-fetch

"FIREBASE_PRIVATE_KEY undefined"
  → Set on Vercel dashboard under Settings > Environment Variables

"Invalid state parameter"
  → Create meta_oauth_state collection in Firestore

"OAuth redirects to error"
  → Check Meta app has correct redirect URI

Slow responses (> 2 seconds)
  → Wait for Firestore indexes to build
