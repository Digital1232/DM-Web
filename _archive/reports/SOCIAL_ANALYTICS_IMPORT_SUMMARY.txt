================================================================================
  DATA FORMAT
================================================================================

CSV STRUCTURE (14 Columns):

  reportDate | postingDate | title | platform | postType | views | likes | 
  shares | comments | followers | reach | client | link | notes

REQUIRED FIELDS (7):
  - reportDate (YYYY-MM-DD format)
  - postingDate (YYYY-MM-DD format)
  - title (text)
  - platform (Facebook|Instagram|YouTube|LinkedIn|X)
  - postType (Video|Image|Reel|Story|Carousel|Text)
  - client (text)

OPTIONAL FIELDS (7):
  - views (number, defaults to 0)
  - likes (number, defaults to 0)
  - shares (number, defaults to 0)
  - comments (number, defaults to 0)
  - followers (number, defaults to 0)
  - reach (number, defaults to 0)
  - link (URL)
  - notes (text)

EXAMPLE ROW:
  2024-01-15,2024-01-14,Summer Campaign Launch,Facebook,Video,2500,180,45,30,25,3200,VilPower,https://facebook.com/post/123,Strong performance

================================================================================
  KEY FUNCTIONS
================================================================================

JavaScript API (in socialAnalyticsImport.js):

1. parseCSV(csvText)
   Input: String with CSV content
   Output: Array of objects (one per row)
   Handles: Quote characters, proper CSV parsing

2. validateAnalyticsRecord(record, rowNumber)
   Input: Record object, row number for error reporting
   Output: {valid: boolean, errors: Array<string>}
   Checks: All required fields, formats, enums

3. processCSVImport(csvText)
   Input: CSV file content as string
   Output: {
     success: boolean,
     data: Array of validated records,
     errors: Array of error messages,
     warnings: Array of warnings,
     summary: {totalRows, validRows, invalidRows}
   }
   Main: Entry point for import processing

4. downloadImportTemplate()
   Input: None
   Output: Triggers browser download of template CSV
   Action: Creates and downloads sample file

5. formatValidationErrors(result)
   Input: Result object from processCSVImport()
   Output: Formatted string for display
   Format: Summary + errors + warnings

HTML Integration Functions (in index.html):

1. handleSocialAnalyticsImport()
   Triggered: When user clicks "Import Data" button
   Action: Reads file, validates, uploads to Firebase
   Updates: UI progress, shows results

2. uploadAnalyticsRecords(records)
   Input: Array of validated records
   Output: Promise<number> - count uploaded
   Action: Pushes each record to Firebase
   Adds: Timestamps, user metadata

================================================================================
  ERROR HANDLING
================================================================================

VALIDATION ERRORS (with examples):

"Row 2: Missing required field 'platform'"
  → Solution: Add platform value to that row

"Row 3: Invalid platform 'facebook'"
  → Solution: Use exact case: 'Facebook'

"Row 4: Invalid reportDate '01/15/2024'"
  → Solution: Use YYYY-MM-DD format: '2024-01-15'

"Row 5: views must be a non-negative number, got '2.5k'"
  → Solution: Use plain number: '2500'

"Row 6: Expected 14 columns, got 12"
  → Solution: Ensure all header columns are present

"CSV must contain header and at least one data row"
  → Solution: Add header row and data rows

"Import limited to 500 records. Your file contains 501"
  → Solution: Split into multiple files

"Row 1: Invalid postType 'video'"
  → Solution: Use exact case: 'Video'

================================================================================
  SUPPORT & TROUBLESHOOTING
================================================================================

COMMON ISSUES:

Q: Import button doesn't appear
A: Check script is loaded, button HTML added, CSS not hidden

Q: File upload doesn't work
A: Verify file is CSV, check Firebase auth, check browser console

Q: Records don't appear after import
A: Check Firebase upload status, refresh page, check user's data node

Q: "Invalid platform" error
A: Platform names are case-sensitive. Use "Facebook" not "facebook"

Q: "Invalid date" error
A: Date format must be YYYY-MM-DD (e.g., 2024-01-15)

Q: Import shows 0 records
A: Verify CSV has header row and data rows, check for extra blank lines

Q: File too large
A: Limit is 500 records. Split into multiple files.
