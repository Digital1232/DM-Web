RACE CONDITION DETECTED:

  Process A (SLOW - 2-3 seconds):
    initClientSettings()
    └─ Firebase listener loads: customClients
       └─ Takes 2-3 seconds (async)

  Process B (FAST - Immediate):
    initStrategyCalendar()
    └─ renderStrategyClientTabs()
       └─ Runs immediately (doesn't wait)
          └─ customClients is EMPTY at this point
             └─ Container rendered: EMPTY ← PROBLEM

  Result: Process B finishes before Process A
          Tabs rendered with empty data
          By the time data loads, rendering is done

  THE FIX (4 PARTS)

PART 1: Preload Function
  ├─ Added: preloadCustomClients()
  ├─ Purpose: Load customClients synchronously from Firebase
  ├─ Timing: 100-300ms (vs 2-3 seconds for listener)
  └─ Result: Data ready when needed

PART 2: Wait Before Rendering
  ├─ Modified: initStrategyCalendar()
  ├─ Change: Now async, waits for preloadCustomClients()
  ├─ Flow: await preloadCustomClients() → then render
  └─ Result: Guaranteed data before rendering

PART 3: Fallback
  ├─ Modified: renderStrategyClientTabs()
  ├─ Change: If customClients empty, use CLIENTS array
  ├─ Guarantee: Tabs always have data
  └─ Result: Never shows empty container

PART 4: Re-render on Update
  ├─ Modified: initClientSettings()
  ├─ Change: Re-render tabs after Firebase async load
  ├─ Timing: After full data arrives
  └─ Result: Tabs update if client list changes
