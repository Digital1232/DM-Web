STEP 1: Install Dependencies (1 minute)
════════════════════════════════════════════════════════════════════════════════

npm install firebase-admin node-fetch

✓ This installs the required packages for backend functions


════════════════════════════════════════════════════════════════════════════════
STEP 2: Commit & Push Backend Code (2 minutes)
════════════════════════════════════════════════════════════════════════════════

git add .
git commit -m "Add Meta OAuth Vercel serverless functions"
git push

✓ Pushes backend files to GitHub
✓ Vercel will auto-deploy on push


════════════════════════════════════════════════════════════════════════════════
STEP 3: Install & Login to Vercel CLI (3 minutes)
════════════════════════════════════════════════════════════════════════════════

npm i -g vercel
vercel login

✓ Install Vercel CLI globally
✓ Login with your Vercel account


════════════════════════════════════════════════════════════════════════════════
STEP 4: Deploy to Vercel (5 minutes)
════════════════════════════════════════════════════════════════════════════════

vercel --prod

Follow the prompts:
  - "Which scope should deploy to?" → Choose your username/org
  - "Link to existing project?" → Yes (if existing) or No (new project)
  - Enter project name if creating new

✓ Your app is now live on vercel.app subdomain
✓ Copy your Vercel URL (e.g., https://your-project.vercel.app)


════════════════════════════════════════════════════════════════════════════════
STEP 5: Set Environment Variables (5 minutes)
════════════════════════════════════════════════════════════════════════════════

vercel env add FACEBOOK_APP_ID
  → Paste: your_app_id

vercel env add FACEBOOK_APP_SECRET
  → Paste: your_app_secret

vercel env add FIREBASE_PROJECT_ID
  → Paste: your_project_id

vercel env add FIREBASE_CLIENT_EMAIL
  → Paste: your_service_account@appspot.gserviceaccount.com

vercel env add FIREBASE_PRIVATE_KEY
  → Paste: entire_private_key_with_newlines

vercel env add MARKETING_HUB_ENCRYPTION_KEY
  → Paste: your_random_32_char_encryption_key

vercel env add APP_URL
  → Paste: https://your-project.vercel.app

✓ All environment variables set
✓ Ready to redeploy with settings


════════════════════════════════════════════════════════════════════════════════
STEP 6: Redeploy with Environment Variables (2 minutes)
════════════════════════════════════════════════════════════════════════════════

vercel --prod

✓ Redeploys with all environment variables
✓ Endpoints now have access to credentials


════════════════════════════════════════════════════════════════════════════════

https://your-project.vercel.app/api/meta/profile

════════════════════════════════════════════════════════════════════════════════
STEP 8: Create Firestore Collections (2 minutes)
════════════════════════════════════════════════════════════════════════════════

In Firebase Console → Firestore Database:

1. Create Collection: meta_connections
2. Create Collection: meta_oauth_state
3. Create Collection: meta_audit_log
4. Create Collection: meta_sync_log

Then on meta_oauth_state:
  - Click TTL (top right)
  - Select expiresAt field
  - Click Enable

✓ Collections ready for data

✓ OAuth working end-to-end

════════════════════════════════════════════════════════════════════════════════
STEP 10: Update Meta App Settings (2 minutes)
════════════════════════════════════════════════════════════════════════════════

  Settings → Basic → App Domains → Add: your-project.vercel.app
  Products → Facebook Login → Settings → Valid Redirect URIs → 
    Add: https://your-project.vercel.app/api/meta/callback

✓ Meta app configured for your Vercel URL
