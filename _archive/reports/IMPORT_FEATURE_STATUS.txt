┌────────────────────────────────────────────────────────────────────────────┐
│ HOW IT WORKS                                                               │
└────────────────────────────────────────────────────────────────────────────┘

  USER CLICKS IMPORT
        ↓
  MODAL OPENS
        ↓
  USER DOWNLOADS TEMPLATE
        ↓
  USER FILLS CSV IN EXCEL/SHEETS
        ↓
  USER UPLOADS CSV FILE
        ↓
  processCSVImport() PARSES
        ↓
  validateAnalyticsRecord() CHECKS EACH ROW
        ↓
  RESULTS DISPLAYED (✓ valid, ✗ invalid)
        ↓
  IF VALID → uploadAnalyticsRecords() UPLOADS
        ↓
  FIREBASE STORES WITH METADATA
        ↓
  initSocialAnalytics() AUTO-REFRESHES
        ↓
  DASHBOARD SHOWS NEW DATA INSTANTLY


┌────────────────────────────────────────────────────────────────────────────┐
│ DATA VALIDATION                                                            │
└────────────────────────────────────────────────────────────────────────────┘

  REQUIRED FIELDS (Must have value):
  ├─ reportDate (YYYY-MM-DD format)
  ├─ postingDate (YYYY-MM-DD format)
  ├─ title (text)
  ├─ platform (Facebook|Instagram|YouTube|LinkedIn|X)
  ├─ postType (Video|Image|Reel|Story|Carousel|Text)
  └─ client (text)

  OPTIONAL FIELDS (Defaults to 0 if empty):
  ├─ views (non-negative integer)
  ├─ likes (non-negative integer)
  ├─ shares (non-negative integer)
  ├─ comments (non-negative integer)
  ├─ followers (non-negative integer)
  └─ reach (non-negative integer)

  OPTIONAL FIELDS (Can be empty):
  ├─ link (URL to post)
  └─ notes (text)
