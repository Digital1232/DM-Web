⚠️ COMMON ISSUES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Issue: Styles not applying
Fix: 
  1. Make sure modern-ui.css is loaded AFTER Tailwind CSS
  2. Clear browser cache (Ctrl+Shift+Delete)
  3. Check CSS file path is correct

Issue: Dark mode not working
Fix:
  1. Verify 'dark' class is on <html> element
  2. Check theme initialization runs on page load
  3. Look for errors in browser console

Issue: Sidebar not collapsing
Fix:
  1. Confirm JavaScript functions are defined
  2. Check toggle button has onclick handler
  3. Verify sidebar element has class 'sidebar'

Issue: Mobile layout broken
Fix:
  1. Check viewport meta tag: <meta name="viewport" ...>
  2. Test with DevTools mobile view
  3. Hard refresh: Ctrl+Shift+R
