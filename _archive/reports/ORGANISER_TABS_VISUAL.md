## Navigation Flow

```
User Action Flow:

1. User with organiser role logs in
                    ↓
2. Sees "📋 Organiser" in sidebar
                    ↓
3. Clicks button
                    ↓
4. Opens Event Organiser view (default)
                    ↓
5. Tab bar visible at top with 5 options
                    ↓
6. User clicks tab (e.g., "Leave")
                    ↓
7. View switches to Leave Organiser
                    ↓
8. Tab indicator updates (Leave now active)
                    ↓
9. User can access form, board, etc.
```

## User Permissions

### Event Organiser User
```
Sidebar: ✅ Sees "📋 Organiser"
Tabs:    ✅ Can access Event tab
         ❌ Other tabs not accessible
Default: Opens Event tab
```

### Admin User
```
Sidebar: ✅ Sees "📋 Organiser"
Tabs:    ✅ Can access All tabs
         ✅ Can switch between any tab
Default: Opens Event tab (can switch)
```

### Regular User
```
Sidebar: ❌ No "📋 Organiser" button
Tabs:    ❌ No access to organiser
```
