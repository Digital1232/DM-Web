# Employee Self Performance Dashboard - Quick Start Guide

## 🚀 Get Started in 30 Seconds

### Step 1: Access the Dashboard
1. Open Reports & Analytics
2. Click "Team Reports"
3. Click "My Performance" tab (new)

### Step 2: View Your Dashboard
- All data loads automatically for last 30 days
- See your 8-section dashboard instantly

### Step 3: Change Time Range (Optional)
1. Click time range dropdown
2. Select: 7, 30, 60, or 90 days
3. Dashboard updates automatically

### Step 4: Export Data (Optional)
1. Click "Export" button
2. CSV file downloads to your computer
3. Open in Excel, Sheets, or your preferred tool

---

## 👥 For Managers/Team Leads

### Switch to Employee Dashboard
1. Click "Team Reports" → "My Performance"
2. Click "Employee" dropdown (visible to managers only)
3. Select employee name
4. View that employee's dashboard
5. Change time range or export as needed

---

## 📊 What You'll See

### Summary Cards (Top)
- **Total Hours Logged** - How many hours you've worked
- **Tasks Completed** - How many tasks finished (with %)
- **Active Clients** - How many different clients you worked on
- **Efficiency Score** - Your productivity score (0-100%)

### Charts & Insights (Below)
- **Work by Type** - How time is split between task types
- **Clients** - Time spent on each client
- **Top Tasks** - Your 10 most time-intensive tasks
- **Hourly Heatmap** - When you work (24-hour pattern)
- **Weekly Trend** - Daily work hours for last 7 days
- **AI Summary** - Smart insights about your work patterns

---

## 🎯 Key Metrics Explained

### Efficiency Score
- Based on task completion rate and productivity
- Range: 0% (Low) to 100% (Excellent)
- Helps you understand your overall performance

### Completion Rate
- Percentage of tasks you've completed
- Example: 78/84 tasks = 93% completion

### Peak Hours
- When you're most productive
- AI recommends scheduling important work during these hours

### Context Switching
- If you work on many clients, AI suggests batching similar tasks

## 🔒 Privacy & Permissions

- **Employees:** See only your own dashboard

No one can see your dashboard without permission.

## ❓ FAQ

### Q: Why does my dashboard show no data?
**A:** You might not have logged any time in the selected date range. Try:
1. Changing date range to "Last 90 Days"
2. Checking if you've logged time recently
3. Verifying your user account is correct

### Q: Can I see my team member's dashboard?
**A:** Yes, if you're a Team Lead or Manager:
1. Click Team Reports → My Performance
2. Use Employee dropdown to select them
3. Their dashboard loads automatically

### Q: How far back can I see data?
**A:** You can select 7, 30, 60, or 90 days. The dashboard shows the most recent data for your selection.

### Q: Can I print my dashboard?
**A:** Yes, two ways:
1. Use browser print (Ctrl+P / Cmd+P)
2. Export to CSV and open in Excel/Sheets

### Q: Why is my efficiency score low?
**A:** Possible reasons:
1. Low task completion rate - focus on finishing tasks
2. Many short sessions - try longer focused work blocks
3. Many different clients - batch similar work together

### Q: Can I see data from other employees?
**A:** Only if you're a manager, team lead, or admin. Employees can only see their own data.

## 🆘 Troubleshooting

### Dashboard Not Loading
- Refresh the page (F5 or Cmd+R)
- Check if "My Performance" tab appears
- Clear browser cache
- Try a different browser

### No Data Showing
- Verify date range has logged time
- Check that you've worked recently
- Try "Last 90 Days" range
- Contact your admin if issues persist

### Export Not Working
- Make sure you have data in selected range
- Check browser download folder
- Try a different browser
- Disable ad blockers

### Charts Not Displaying
- Refresh the page
- Check browser console for errors (F12)
- Clear browser cache
- Try different browser
