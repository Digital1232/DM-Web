## 📊 How It Works

### Data Flow
```
User in One Desk
    ↓
Opens Social Analytics Hub
    ↓
Clicks "Download Report"
    ↓
Selects Client/Month/Year
    ↓
NEW: Clicks "📊 Dashboard"
    ↓
Data saved to browser's localStorage
    ↓
analytics-dashboard.html opens in new tab
    ↓
Dashboard loads data from localStorage
    ↓
All charts and metrics populate
    ↓
Beautiful report displayed!
```

### Data Structure
```javascript
{
  entries: [
    {
      post: "Post Title",
      postDate: "2026-07-09",
      postType: "Video",
      views: 14326,
      likes: 309,
      comments: 112,
      shares: 137
    },
    // More posts...
  ],
  client: "NTT",
  month: 7,
  year: 2026
}
```

## 📞 Support

### Common Questions

**Q: Dashboard won't open?**  
A: Check if popup blocker is enabled. Allow popups for this domain.

**Q: Charts don't show?**  
A: Clear browser cache. Try different browser. Check console for errors.

**Q: Print doesn't work?**  
A: Use Ctrl+P (or Cmd+P on Mac). Make sure you're in the dashboard.

**Q: Data looks wrong?**  
A: Verify you selected correct client/month/year. Refresh browser.

**Q: Want to customize?**  
A: See "Customization" section above or read DASHBOARD_QUICK_REFERENCE.md
