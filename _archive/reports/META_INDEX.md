## 🔑 Key Concepts

### OAuth Flow
User → App → Facebook → App → Firestore → User

See: `META_BACKEND_IMPLEMENTATION.md` → OAuth Security

### CSRF Protection
State parameter + 10-minute expiration = Secure OAuth

See: `META_BACKEND_IMPLEMENTATION.md` → CSRF Protection

### Token Encryption
AES-256-CBC encryption at rest

See: `META_BACKEND_IMPLEMENTATION.md` → Token Encryption

### API Endpoints
6 endpoints covering: connect, callback, profile, refresh, sync, disconnect

See: `META_BACKEND_IMPLEMENTATION.md` → API Endpoints

### Firestore Collections
4 collections: connections, oauth_state, audit_log, sync_log

See: `META_BACKEND_IMPLEMENTATION.md` → Firestore Collections

## 📱 Endpoints Summary

```
POST   /api/meta/connect           Get OAuth URL
GET    /api/meta/callback          Handle OAuth callback
GET    /api/meta/profile           Fetch connection data
POST   /api/meta/refresh           Validate connection
POST   /api/meta/sync              Sync latest data
POST   /api/meta/disconnect        Disconnect account
```

See: `META_BACKEND_IMPLEMENTATION.md` → API Reference for details
