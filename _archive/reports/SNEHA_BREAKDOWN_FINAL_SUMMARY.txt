     - Gets all content items Sneha worked on for a task

  2. formatTaskBreakdown(taskId, task, snehaSelections, qcReports)
     - Formats complete breakdown display info
     - Returns: { breakdown: "[ Items ]", category: "...", labels: [...] }

  - Firebase: worksync/sneha_work_selections (Sneha's content selections)
  - Firebase: worksync/qc_reports (QC reviews performed)
  - Local: snehaSelections array (loaded from Firebase)
  - Local: qcReports array (loaded from Firebase)
  - Local: tasks array (all tasks)

Display Logic:
  1. For each task in completed list

  3. Display: Title + breakdown (purple) + category (gray) + status badge
