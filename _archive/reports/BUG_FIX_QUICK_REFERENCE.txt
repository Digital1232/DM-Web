🔴 PROBLEM:
───────────────────────────────────────────────────────────────────────────────
Employee Self Performance Dashboard renders completely blank - no data, no charts, no content.

🐛 ROOT CAUSE:
───────────────────────────────────────────────────────────────────────────────
Variable Shadowing Bug in getSelectedEmployeeForDashboard()

BUGGY CODE:
    function getSelectedEmployeeForDashboard() {
        const currentUser = currentUser?.email || ...  // ❌ WRONG
    }

PROBLEM:
    • Local variable named "currentUser" shadows global "currentUser"
    • Reading undefined variable results in error or 'Unknown'
    • Employee name is wrong
    • Data aggregation fails
    • Dashboard stays empty

✅ SOLUTION:
───────────────────────────────────────────────────────────────────────────────
Fixed Variable Shadowing

FIXED CODE:
    function getSelectedEmployeeForDashboard() {
        const employeeName = (typeof currentUser !== 'undefined' && currentUser)
            ? (currentUser.email || currentUser.name || 'Unknown')
            : 'Unknown';
        return employeeName;
    }

FIX DETAILS:
    ✓ Renamed local variable to "employeeName" (no shadowing)
    ✓ Safely checks if global "currentUser" exists
    ✓ Properly extracts email/name
    ✓ Returns correct employee name
