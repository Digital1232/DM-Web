================================================================================
                            TROUBLESHOOTING
================================================================================

ISSUE: Upload area doesn't appear
FIX: 
  1. Refresh the page (Ctrl+F5 or Cmd+Shift+R)
  2. Clear browser cache
  3. Check if index.html was updated

ISSUE: Upload button appears but upload fails
FIX:
  1. Open browser console (F12)
  2. Look at error message in Console tab
  3. Common errors:
     - "Failed to fetch" = PHP file not at right path
     - "404 Not Found" = PHP file doesn't exist
     - "CORS error" = Domain URL wrong
  4. Verify: public_html/api/upload-task-file.php exists

ISSUE: "Permission Denied" error
FIX:
  1. Go to Hostinger File Manager
  2. Right-click uploads folder
  3. Click "Permissions"
  4. Change to: 755 (for folders), 644 (for files)
  5. Click "Apply to all files/folders"
  6. Wait and retry

ISSUE: Upload hangs or times out
FIX:
  1. Try smaller file first (< 10 MB)
  2. Check internet connection
  3. Wait longer (up to 5 minutes for large files)
  4. Try different file type

ISSUE: Can upload but attachment doesn't save with task
FIX:
  1. Verify task is actually updating (make other change)
  2. Check browser console for JavaScript errors
  3. Verify index.html has latest code
