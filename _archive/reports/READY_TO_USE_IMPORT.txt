  QUICK START - FOR USERS
================================================================================

WHERE TO FIND IT:
→ Open the application
→ Click "Social Analytics" in the left sidebar
→ Look for the GREEN "Import" button in the header (next to "Add Entry")

HOW TO USE IN 3 STEPS:

1️⃣  CLICK IMPORT BUTTON
    └─ Opens the import dialog

2️⃣  DOWNLOAD & FILL TEMPLATE
    ├─ Click "Download CSV Template"
    ├─ Open in Excel or Google Sheets
    ├─ Fill in your social media data
    └─ Save as CSV

3️⃣  UPLOAD & IMPORT
    ├─ Click "Choose File"
    ├─ Select your CSV file
    ├─ Click "Import Data"
    └─ See your data in the dashboard! ✨

THAT'S IT! Records appear instantly.

================================================================================
  WHAT YOU CAN IMPORT
================================================================================

Each record includes:
  ✓ Report Date (when metrics were recorded) - Required
  ✓ Posting Date (when post was published) - Required
  ✓ Title (post description) - Required
  ✓ Platform (Facebook, Instagram, YouTube, LinkedIn, X) - Required
  ✓ Post Type (Video, Image, Reel, Story, Carousel, Text) - Required
  ✓ Client/Brand Name - Required
  ✓ Views, Likes, Shares, Comments, Followers, Reach - Optional
  ✓ Link to Post - Optional
  ✓ Notes/Comments - Optional

MAXIMUM: 500 records per import

EXAMPLE ROW:
  2024-01-15 | 2024-01-14 | Summer Campaign | Facebook | Video | 2500 | 
  180 | 45 | 30 | 25 | 3200 | VilPower | https://... | Notes here

================================================================================
  TROUBLESHOOTING
================================================================================

Q: Where is the Import button?
A: In Social Analytics dashboard header, GREEN button next to "Add Entry"

Q: The button doesn't appear?
A: You may need admin permissions. Contact your administrator.

Q: How do I format dates?
A: Use YYYY-MM-DD format (e.g., 2024-01-15)

Q: Can I use "facebook" instead of "Facebook"?
A: No, platform names are case-sensitive. Use: Facebook, Instagram, YouTube, LinkedIn, X

Q: What happens if some records have errors?
A: Valid records import, invalid ones are skipped. You'll see which rows failed.

Q: Can I import more than 500 records?
A: No, limit is 500 per import. Split into multiple files if needed.

Q: Do my records appear right away?
A: Yes! Dashboard refreshes immediately after upload.

Q: Can I edit imported records?
A: Yes! Click the "Edit" button on any record to modify it.
