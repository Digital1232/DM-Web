# Quick Start: Sharing Documents in Chat

## The Problem You Had
❌ Google Drive links weren't working in chat messages  
❌ Had to upload files instead of sharing links

## The Solution
✅ New Google Drive button in chat input  
✅ Share any document link (Google Drive, OneDrive, Dropbox, etc.)  
✅ Mix links and files in the same message

---

## How to Use

### Step 1: Click the Google Drive Icon
In the chat input area, you'll see a new button with the Google Drive icon next to the file attachment button.

```
[📎 File Button] [🔗 Google Drive Button] [Message Input] [Send]
```

### Step 2: Fill in the Modal
A modal will pop up with 3 fields:

1. **Document Name** - What you want to call it
   - Example: "Q3 Budget Report"
   
2. **Document Link** - The shareable URL
   - Paste your Google Drive link here
   - Also works with: OneDrive, Dropbox, any cloud storage URL
   
3. **Document Type** - What kind of file it is
   - Select from: PDF, Document, Spreadsheet, Presentation, Google Docs, Google Sheets, etc.

### Step 3: Click "Add to Message"
The document will appear in your staged attachments (under the input field).

### Step 4: Send Your Message
Type any additional message text (optional) and click Send.

---

## Example Workflow

**Scenario:** You want to share a Google Sheet with your team

1. Open your Google Sheet
2. Click Share → Get link → Copy the link
3. In the chat app, click the 🔗 Google Drive button
4. Fill in:
   - **Name:** "Team Budget Tracker"
   - **Link:** `https://docs.google.com/spreadsheets/d/...`
   - **Type:** Google Sheets
5. Click "Add to Message"
6. (Optional) Type: "Please review the updated numbers"
7. Click Send ✓

Recipients will see the link attachment and can click to open it!

---

## Tips & Tricks

✅ **Mix attachments:** You can add both files AND links in the same message
✅ **Multiple links:** Add multiple document links to one message
✅ **Supports multiple services:**
   - Google Drive
   - Microsoft OneDrive
   - Dropbox
   - Any other cloud storage with shareable links

❌ **What won't work:**
   - Private links (the link must be shareable/accessible to recipients)
   - Broken/expired links
   - Links that require special authentication

---

## Troubleshooting

| Issue | Solution |
|-------|----------|
| "Please enter a valid URL" error | Make sure your link starts with `https://` |
| "Please enter a document name" error | Fill in the "Document Name" field |
| Recipients can't access the link | Make sure the share settings are "Anyone with the link can view" |
| Link doesn't appear in message | Check that you clicked "Add to Message" button |
