# How to Upload Files to Chat

## Quick Start

### Uploading a File

1. **Open a chat conversation**
2. **Click the paperclip icon** (📎) in the message input area
3. **Select your file** from your computer
4. The file will appear below the input box showing:
   - File icon
   - File name
   - File size
5. **Type your message** (optional)
6. **Click Send** button
7. Your file is uploaded to Google Drive and shared in the chat!

---

## What Happens

✅ **File is uploaded to Google Drive** - Stored securely in the cloud  
✅ **File appears in chat** - Everyone in the conversation can see it  
✅ **Shareable link sent** - Recipients can view/download directly from Google Drive  
✅ **Organized by conversation** - Files grouped by chat thread  

---

## File Size Limits

- **Maximum per file**: 100 MB
- **Recommended**: Files under 50 MB upload faster
- **Large files**: 50-100 MB may take 10-30 seconds

---

## How to Download Files

### Option 1: View in Chat
1. Look at the file message in chat
2. Click on the **file name** or **preview**
3. Opens in Google Drive viewer
4. Click **Download** icon in top right

### Option 2: Direct from Google Drive
1. The file is stored in your Google Drive
2. Go to your Google Drive
3. Find the "Chat Files" folder
4. Navigate to the conversation folder
5. Download the file directly

### Option 3: From Message Link
1. Right-click the file message
2. Select "Copy link"
3. Paste in browser to download

---

## Uploading Multiple Files

1. Click the paperclip icon (📎)
2. Hold **Ctrl** (or **Cmd** on Mac) while selecting files
3. Select multiple files at once
4. All files will appear in the upload area
5. Send the message
6. All files upload to Google Drive

---

## File Management

### View All Files from a Conversation
1. Go to Google Drive
2. Open "Chat Files" folder
3. Find your conversation folder
4. All files are listed there

### Download All Files at Once
1. Open the conversation folder in Google Drive
2. Select all files
3. Right-click > **Download**
4. Files download as a ZIP archive

### Delete a File
⚠️ **Note**: Once deleted from Google Drive, the file is gone from the chat  

If needed to remove a file:
1. Go to Google Drive
2. Find the file in the conversation folder
3. Right-click > **Delete**

---

## Sharing Files Outside the Chat

### Get a Shareable Link
1. Right-click the file in Google Drive
2. Click **Share**
3. Change sharing settings as needed
4. Copy the link
5. Send to anyone (even outside the chat)

### Make File Public
1. Right-click file > **Share**
2. Change to "Anyone with the link can view"
3. Copy and share the link

---

## Common Issues

| Problem | Solution |
|---------|----------|
| File didn't upload | Check your internet connection and try again |
| Taking too long | Large files may take 10-30 seconds, wait a bit longer |
| File still uploading when I close chat | It will continue uploading in the background |
| Can't see the file | Refresh the page or the chat |
| File won't open | Try downloading and opening locally on your computer |
| Permission denied | Ask your admin to verify Google Drive setup |

## Privacy & Security

✅ **Your files are secure**
- Stored in Google Drive with encryption
- Only people in your team can access
- Organized by conversation
- Audit trail shows who uploaded what

✅ **Your data is backed up**
- Google Drive keeps version history
- Files can be recovered if deleted (within 30 days)
- Automatic cloud backup

⚠️ **Things to keep in mind**
- Don't upload sensitive passwords or secrets
- Remember others in the chat can see all files
- Files stay in Google Drive even after chat is deleted
- Use Google Drive's sharing settings if you need to restrict access

## Tips & Tricks

### Faster Uploads
- Use files under 10 MB for fastest upload
- Compress large files before uploading
- Check internet speed

### Better Organization
- Name files clearly (good: "Q3-Report-Final.pdf" vs bad: "file123.pdf")
- Use descriptions when uploading related files
- Reference file names in your message text

### Mobile Users
- Tap the **📎** icon to select files from your phone
- Photos can be uploaded directly
- Works with cloud storage apps (Google Drive, OneDrive, etc.)

### Desktop Users
- Drag and drop files directly into chat (coming soon)
- Use keyboard shortcuts to open file picker
- Bulk upload multiple files at once

## Getting Help

If you run into issues:
1. Check this guide first
2. Ask your team admin
3. Try uploading a different file to test
4. Check your internet connection
5. Refresh the chat and try again
