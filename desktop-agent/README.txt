One Desk - App Usage Tracker (Windows)
======================================

Records which apps and websites you use, and for how long, ONLY while you are
checked in on One Desk (not on a break). Results show in One Desk > App Usage.

INSTALL
  1. Extract this zip (right-click > Extract All).
  2. Double-click install.cmd.
     If Windows says "Windows protected your PC": More info > Run anyway.
  3. Type Y, then sign in with your One Desk email and password.
  No admin rights needed. It starts automatically with Windows.

WHAT IS RECORDED
  - The name of the app in front (Photoshop, After Effects, Chrome ...)
  - For browsers, the site name when known (YouTube, Instagram, Canva ...)
  - Minutes per app, and Idle time (no mouse/keyboard for 2+ minutes)

NEVER RECORDED
  Window titles, page addresses, keystrokes, screenshots, files, messages.

REMOVE
  Run %LOCALAPPDATA%\OneDeskTracker\uninstall.cmd

TROUBLESHOOTING
  Log file: %LOCALAPPDATA%\OneDeskTracker\agent.log
  Changed your One Desk password? Run install.cmd again.
