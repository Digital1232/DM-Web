2. Click: Firestore Database (in left menu)
3. Click: Create Collection

   - Click: Create

4. Click: Create Collection
   - Enter: meta_oauth_state
   - Click: Create
   - IMPORTANT: Enable TTL
     * Click on meta_oauth_state collection
     * Click "TTL" (top right menu)
     * Select: expiresAt field
     * Click: Enable

5. Create: meta_audit_log (optional)
   - Click: Create Collection
   - Enter: meta_audit_log
   - Click: Create

6. Create: meta_sync_log (optional)
   - Click: Create Collection
   - Enter: meta_sync_log
   - Click: Create
