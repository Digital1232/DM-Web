═══════════════════════════════════════════════════════════════════════════════
  HOW IT WORKS - TECHNICAL PERSPECTIVE
═══════════════════════════════════════════════════════════════════════════════

Upload Process:
───────────────
1. User selects file(s)
2. handleTaskFileUpload() validates file size
3. uploadTaskFile() sends multipart form data to PHP
4. PHP validates:
   • File type (MIME check)
   • File size (< 100 MB)
   • Generates safe filename
5. PHP saves file to /uploads/task-attachments/
6. PHP returns file URL + metadata
7. File added to currentTaskAttachments array
8. renderTaskAttachments() updates UI

Save Process:
─────────────
1. User clicks "Update Task"
2. submitTaskUpdate() collects form data + attachments
3. attachments array saved with task
4. Update sent to Firebase (stores URL only, not file)
5. Task saved with attachment URLs

Load Process:
─────────────
1. User opens task to edit
2. openEditTaskModal() reads task data
3. Loads currentTaskAttachments = task.attachments
4. renderTaskAttachments() displays list
5. Each file shows as clickable item with icon

  SECURITY FEATURES
═══════════════════════════════════════════════════════════════════════════════

✅ File Type Validation
   • Only specific MIME types allowed
   • Validated server-side (can't bypass)
   • Rejects executables, scripts, etc.

✅ File Size Limits
   • Maximum 100 MB per file
   • Prevents disk abuse

✅ Safe Filenames
   • Auto-generates: task_<timestamp>_<random>.ext
   • Prevents directory traversal attacks
   • Original name preserved in metadata

✅ Permissions
   • Upload folder: 755 (read/execute, not write)
   • Files: 644 (read-only, non-executable)
   • Scripts can't run from uploads

✅ CORS Headers
   • Requests restricted to domain
   • API endpoint protected
